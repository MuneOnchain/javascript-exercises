# Data types

- number: `5`, `3.14`
- string: `"5"`, text in quotes
- boolean: `true` / `false`
- null: nothing, set on purpose
- undefined: no value was ever given

`typeof null` gives "object". It's an old bug in JavaScript.

Template literal:

```javascript
let name = "Muneeb";
console.log(`Hello, ${name}!`);
```
