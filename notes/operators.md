`+=` is the addition assignment operator. It adds a value to a variable that already holds a value.

```javascript
let score = 20;
score += 3; // score is now 23
```

`-=` is the subtraction assignment operator. it subtracts a value from a variable that already holds a value.

```javascript
let score = 30;
score -= 7; // score is now 23
```

`*=` is the multiplication assignment operator. it multiplies the existing variable value with the new given value.

```javascript
let score = 4;
score *= 3; // score is now 12
```

`/=` is the division assignment operator. it divides the existing variable value by new given value.

```javascript
let score = 20;
score /= 2; // score is now 10
```
